# 巫师3 双语字幕 mod 生成器

给《巫师3：狂猎》重制版（5.x）做一个**只做字幕**的双语字幕 mod：任选两种官方语言，
主副字幕同时显示。

```text
我好想、好想回到家乡
I long, I long to be homeward bound
```

不是翻译 mod，也不需要联网：直接读你本机游戏里的官方字符串表，把两种语言按字符串 ID
对齐后合并，生成一个放进 `Mods/` 就能用的 mod。

- 官方 18 种语言任选两种（简中/繁中/英/日/俄/法/德/波/西/意/捷/匈/阿/巴葡/韩/土/乌/墨西）
- 只动字幕：菜单、物品名、任务名、技能说明一律保持主语言
- 纯数据 mod：不含脚本，**不需要 REDkit**，不碰游戏原始文件，不动存档，删掉文件夹即可还原
- 大小约 10MB，秒级生成

---

## 快速开始

**双击 `生成双语字幕.bat`**，按提示选两种语言即可（会先自动找到游戏目录）。

也可以用命令行：

```powershell
# 交互模式
python -m w3dualsub

# 一步到位：简中主字幕 + 英文字幕，直接装进游戏
python -m w3dualsub build --primary cn --secondary en --install

# 只看有哪些语言可用
python -m w3dualsub languages
```

进游戏后确认两件事：**选项 → 语言 → 文本语言 = 主字幕语言**，以及**字幕已打开**。

卸载：删掉 `游戏目录/Mods/modW3DualSub`（或 `python -m w3dualsub uninstall`）。

## 命令行参数

| 参数 | 说明 |
|---|---|
| `--primary` / `--secondary` | 主/副字幕语言代码，默认主语言取游戏当前文本语言，副语言取 `en` |
| `--mode dialogue` | **默认**，只合并台词（无本地化键的字符串） |
| `--mode all` | 连界面、物品、任务文本一起双语 |
| `--sep auto` | **默认**，整句换行、短语用空格分隔 |
| `--sep br` / `space` / `pipe` / `newline` | 强制指定分隔方式 |
| `--only-sentences` | 只合并以标点结尾的完整句子，界面最干净，但会漏掉短台词 |
| `--max-chars 300` | 主语言原文超过 300 字就不合并（书籍/怪物图鉴/任务回顾不是字幕）；`0` 不限 |
| `--layout overlay` | **默认**，只写改动条目，汇总成一个 `<主语言>.w3strings` |
| `--layout mirror` | 逐资源完整替换（排查问题用，文件更大） |
| `--out DIR` | 生成目录，默认 `./build` |
| `--install` | 生成后直接复制进 `Mods/` |

其他子命令：`languages`（列语言）、`inspect --lang en`（看资源与台词样例）、
`uninstall`、`gui`（需要 Tkinter）。

## 原理（一句话版）

游戏把每种语言的文本存在 `content/content0/<语言>.w3strings` 里，条目 = 「字符串 ID →
文本」，另外还有一张「本地化键哈希 → ID」的表。**台词没有键哈希**（场景文件直接按 ID
引用），界面文本才有键哈希（`panel_xxx`、`item_xxx`）。所以「只做字幕」只要合并
**没有键哈希的条目**即可，界面文本在数据层面根本没被碰过。

mod 的 `.w3strings` 会被叠加进同一语言的字符串库、按 ID 覆盖，所以生成的 mod 只需要包含
被改动的台词条目（约 8 万条），不需要整表复制。

格式细节、验证方法、风险分析见 [`docs/技术说明.md`](docs/技术说明.md)。

## 已验证到什么程度

- **编码器**：拿本机重制版 5.01 的真实文件做回环测试，重编码后与官方文件**逐条密文
  完全一致**（英/简中/繁中各 9.6~9.8 万条，0 条不一致），索引顺序、长度、缓冲单元数全对。
- **字幕识别**：真实文件里 `content/content0/cn.w3strings` 有 97,835 条，其中 80,712 条
  无键哈希，抽样内容全部是对白台词。
- **合并结果**：简体中文 + 英文 → 79,219 条台词双语（81%），成品 10.5MB；其余是界面文本、
  副语言缺条目、未翻译条目和超长书籍文本。
- **自动化测试**：36 个单元/集成测试（编解码、字节序、bit6 变长计数、合并策略、幂等性、
  生成/安装/卸载），`python -m unittest discover -s tests -t .` 全绿。

未验证的只有「进游戏看效果」这一步 —— 需要你自己跑一次。

## 已知限制

1. **预渲染影片的字幕不双语**。开场的「前情提要」、结局 CG 等十几个 `.usm` 影片，字幕是
   嵌在视频文件里的独立轨道（`.subs`），要改就得重打包 3~4GB 的 `movies.bundle`。本 mod
   不处理这些片段；引擎内实时渲染的对话、过场、旁白全部生效（占全游戏字幕的绝大多数）。
2. **字幕框高度有限**。中英双行时字号太大可能挤出框外，可在「选项 → 显示 → 字幕大小」
   调小。
3. **台词选择轮盘**也会变成双语（它和台词共用字符串），属于同一套字幕数据。
4. 若你之前装过**覆盖式**的双语 mod（直接改了 `content`/`DLC` 里的原文件），那些文件里
   已经是「中文`<br>`English」。本工具能识别并跳过，不会叠成两遍英文；但更推荐先用
   Steam/GOG 的「验证文件完整性」还原原始文件再重新生成。

## 故障排查

| 现象 | 处理 |
|---|---|
| 完全没有变化 | 确认 `Mods/modW3DualSub/content/<语言>.w3strings` 存在；游戏要完全退出再启动；文本语言 = 主语言 |
| 字幕里出现字面 `<br>` | 用 `--sep space` 重新生成 |
| 菜单/物品也被双语了 | 用了 `--mode all`，改回默认 `--mode dialogue` |
| DLC（血与酒/石之心）台词没双语 | 用 `--layout mirror` 重新生成试试；若你的 DLC 语言文件本身只有中文，则需要先确认该语言资源存在 |
| 某几句只有单语言 | 副语言里缺同 ID 条目（多语言版本内容长度不同），属于正常损耗 |
| 想临时关掉 | 把 `Mods/modW3DualSub` 改名为 `modW3DualSub.off` |

## 目录结构

```
w3dualsub/
  language.py    语言表（语言密钥 / 混淆掩码 / 母语名称）
  w3strings.py   .w3strings 读写（含 bit6 变长计数、逐字符旋转异或）
  merge.py       双语合并策略（台词识别、分隔符、幂等检测）
  discover.py    找游戏目录（Steam/GOG/Epic/手动）、清点语言资源
  build.py       生成 mod、校验、安装/卸载
  cli.py         命令行 + 交互向导
  gui.py         Tkinter 界面（可选）
tests/           36 个测试
build/           生成产物（modW3DualSub/ 就是 mod 本体）
```
